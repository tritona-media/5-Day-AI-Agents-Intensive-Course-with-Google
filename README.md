# 5-Day-AI-Agents-Intensive-Course-with-Google
This course is about building single and multi agent systems encompassing architecture, tool usage (incl. MCP), memory, evaluation and deployment.

It is divided into 5 days. Each day covers a differnt topic.

Day 1: Introduction to Agents

Day 2: Agent Tools & Interoperability with Model Context Protocol (MCP)

Day 3: Context Engineering: Sessions & Memory

Day 4: Agent Quality

Day 5: Prototype to Production

You can find the course on Kaggle: https://www.kaggle.com/learn-guide/5-day-agents.

In order to thoroughly understand the topics a 2 file strategy is used:
1. **`01_<file-name>.py`**: This is the original code from Kaggle.
2. **`02_<file-name>_experiment.py`**: This is a modification of the original code for experimenting.
